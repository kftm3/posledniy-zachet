## Эмоции и род диалогов (v49)

В сценовом коде можно отправлять событие `game:dialogue-line`, чтобы менять эмоцию выбранного персонажа и подставлять вариант реплики для выбранного пола. Поддерживаемые эмоции: `normal`, `confident`, `smile`, `thinking`, `worried`.

Пример:
```ts
window.dispatchEvent(new CustomEvent('game:dialogue-line', {
  detail: {
    emotion: 'worried',
    targetId: 'dialogue-text',
    maleText: 'Ты готов ответить?',
    femaleText: 'Ты готова ответить?'
  }
}));
```

Важно: в текущем проекте ещё нет подключённого сюжетного экрана с репликами, поэтому это событие — готовый мост для будущего сценария, а не массовая правка отсутствующих диалоговых сцен. На данный момент подключённый первый мужской пресет и все пять женских пресетов поддерживают смену эмоций. Для остальных мужских пресетов логика активируется после добавления их изображений и спрайтов в экран.


## Первая сюжетная сцена — коридор (v50)

После нажатия «Начать игру» на студенческом билете открывается коридорная сцена. Реплики подбираются по архетипу из полного сценария; выбранный персонаж показывает эмоции по ходу диалога. После реплик доступны три варианта настроя перед входом в аудиторию. Фон коридора и прозрачная рамка диалога лежат в `public/assets/corridor-background.png` и `public/assets/corridor-dialogue-frame.png`.
